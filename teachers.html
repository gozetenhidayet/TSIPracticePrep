How Teacher Classroom Works

From room creation to targeted reteaching in six steps.

1Create a roomChoose TSIA2, SAT, or ACT; test length; timed or untimed; and Same Questions or Different Questions.
2Share the class codeStudents join with Class Code + First Name + Last Initial + Grade. They do not need a student account.
3Control the sessionUse Start All, Pause All, Continue All, End, Lock All, and Unlock All. Secure Timed Mode can lock a student after focus/fullscreen warnings without losing saved progress.
4Watch live progressSee who joined, who is working, who finished, progress percentage, and current class average.
5Analyze errorsOpen Questions, Students, and Skills to inspect missed questions, selected wrong choices, timing, skill accuracy, and error patterns.
6Reteach efficientlyUse Assign Similar Questions, Add to Reteach Set, or targeted practice so students work on the exact skill that needs attention.
Same Questions mode supports direct question-by-question comparison. Different Questions mode should be compared by equivalent skill and difficulty, not by raw item number.
