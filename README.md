# ScorePath Practice

Private staging repository for ScorePath Practice.

## Before publishing
1. Keep repository PRIVATE.
2. Do NOT enable GitHub Pages yet.
3. Review `index.html` locally / via provided preview images.
4. Replace placeholder domain in `sitemap-template.xml`.
5. Replace placeholder AdSense publisher ID in `ads.txt-template.txt` only after AdSense setup.
6. When ready to publish, enable GitHub Pages and then configure the custom domain/DNS.
