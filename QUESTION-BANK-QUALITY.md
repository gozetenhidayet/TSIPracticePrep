# ScorePath Question Bank Quality Standard — V19

## Non-negotiable rule
Quality is more important than hitting a question-count target. A question must be blocked from student delivery if its answer key, wording, explanation, skill alignment, or distractor analysis is uncertain.

## Automatic structural gate
Every active item must have a unique ID, valid answer, unique choices, explanation, choice-by-choice rationale, skill, difficulty, exam/section label, and reusable strategy.

## Editorial gate
Structural validation is not the same as academic verification. New templates should be sampled and reviewed by a qualified human editor before large-scale publication. Flagged templates should be disabled at the template level so all generated variants are blocked.

## Originality
ScorePath may study official public blueprints and released practice material for skills, tone, difficulty and distractor behavior. It should not reproduce an administered/released question with only small wording, number, or name substitutions. Questions should use new contexts, data, reasoning paths and distractors while measuring the same type of skill.

## Rotation
Correct-answer positions should be balanced across A/B/C/D over a set. Students should preferentially receive unseen items. A missed item should first trigger a new similar item, then return later through spaced review.
