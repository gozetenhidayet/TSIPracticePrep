What can a teacher do here?

From creating a room to targeted reteaching, in six steps — this is the same classroom tool a signed-in teacher account opens after signing in above.

1Create a roomPick TSIA2, SAT, or ACT; set the test length; timed or untimed; and choose Same Questions (everyone gets identical items, for question-by-question comparison) or Different Questions (each student gets their own equivalent, blueprint-fair set).
2Share the class codeStudents join with just a Class Code + First Name + Last Initial + Grade — no student account required.
3Control the live sessionStart All, Pause All, Continue All, End, Lock All, Unlock All. Secure Timed Mode can auto-lock a student after tab/fullscreen warnings without losing their saved progress.
4Watch live progressSee who's joined, who's working, who's finished, each student's progress percentage, and the live class average.
5Analyze real errorsOpen the Questions, Students, or Skills tab to see exactly which items were missed, which wrong choice was picked, how long each question took, and per-skill accuracy.
6Reteach efficientlyUse Add to Reteach Set, Flag for Class Reteach, or a per-student skill flag so students work the exact skill they actually got wrong, instead of a generic review.
